# SEBI Cybersecurity & Cyber Resilience Framework (CSCRF 2024)

## Part III - Artificial Intelligence and Emerging Technologies
* **Rule 6.2 (Input Validation & Algorithmic Guardrails)**: Mandatory pre-processing verification of all prompts, model inputs, and automated tool commands to prevent adversarial prompt injection, jailbreak attacks, and model hallucination hazards in market-critical systems.

## Part II - Data Protection & Network Defense
* **Rule 4.1**: Non-Public Financial Information (PAN, Demat Account ID, GSTIN, CIN) protection.
* **Rule 5.3**: Real-time URL filtering and phishing interception for all automated web and external network tools.
